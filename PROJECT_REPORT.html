Product Inventory Management REST API

Java Programming — Practical Semester Project
Project: Product Inventory REST API
Technology: Spring Boot 3, JPA & MySQL
Server Port: 8081
Base URL: http://localhost:8081/api/products

1. Entity Requirements

The Product entity represents inventory items, mapped to the MySQL products table using Spring Data JPA.

Attribute Data Type Constraints & Description
id Long Primary Key, Auto-incremented (@Id, @GeneratedValue(strategy = GenerationType.IDENTITY))
name String Product name (@NotBlank)
category String Product category (e.g. Electronics, Office) (@NotBlank)
price Double Item price (@NotNull, @DecimalMin("0.01"))
stockQuantity Integer Available inventory quantity (@NotNull, @Min(0))
sku String Unique Stock Keeping Unit (@NotBlank, unique = true)

2. REST API Endpoints Specification

Method Endpoint Description Status Code
POST /api/products Add a new product 201 Created
GET /api/products Retrieve all products 200 OK
GET /api/products/{id} Retrieve product by ID 200 OK (or 404 Not Found)
PUT /api/products/{id} Update product details & stock 200 OK (or 404 Not Found)
DELETE /api/products/{id} Delete a product by ID 200 OK (or 404 Not Found)
GET /api/products/category/{category} Retrieve products filtered by category 200 OK

3. Database Configuration (MySQL)

Configured in src/main/resources/application.properties:

server.port=8081
spring.datasource.url=jdbc:mysql://localhost:3306/inventory_db?useSSL=false&serverTimezone=UTC&allowPublicKeyRetrieval=true&createDatabaseIfNotExist=true
spring.datasource.username=root
spring.datasource.password=root
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQLDialect

5. Exception Handling Architecture

Centralized exception handling is implemented using @RestControllerAdvice in GlobalExceptionHandler.java:

  • ResourceNotFoundException: Thrown when product ID does not exist in MySQL. Returns HTTP 404 Not Found.
  • MethodArgumentNotValidException: Catches validation errors (e.g. blank name, negative price, or negative stock). Returns HTTP 400 Bad Request.
  • Exception: Handles unexpected runtime server exceptions with HTTP 500 Internal Server Error.
